A clean, standards-compliant sample plugin: a Client Notes custom post type with a rating admin column and a shortcode.

== Description ==

This is the known-CLEAN sample used as the quality bar for the AI WP Plugin Builder verification harness.
It registers a private "Client Note" custom post type, adds a Rating column to its admin list table, and
provides a `[client_notes count="5"]` shortcode that lists recent notes.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate through the Plugins screen.
3. Add Client Notes from the admin menu; embed `[client_notes]` in any post or page.

# Greeting Box

A very small plugin that provides a single shortcode `[greeting_box]` for the front end.

- The shortcode accepts one optional attribute `name` (default "World").
- It outputs a friendly greeting like "Hello, World!" wrapped in a `<div class="greeting-box">`.
- The name attribute must be sanitized and the output fully escaped.

No admin screens, no custom post types, no database storage. Keep it minimal.

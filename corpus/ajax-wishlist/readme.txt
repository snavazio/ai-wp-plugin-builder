== Description ==

Adds a [wishlist_button] shortcode for users to add the current post to a per-user wishlist via AJAX (logged-out allowed, stored in a cookie-keyed option).

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate through the Plugins screen.

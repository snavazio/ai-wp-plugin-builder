== Description ==

Event CPT with start-date and location meta, admin Start Date column, and [events] shortcode for upcoming events. All output escaped, input sanitized, with nonce and capability checks.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate through the Plugins screen.

== Description ==

Adds a [color_note] shortcode for creating colored note boxes. The shortcode accepts a 'color' attribute (default: blue) from a predefined set of colors: blue, green, red, yellow, purple, orange, gray, black, white.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate through the Plugins screen.

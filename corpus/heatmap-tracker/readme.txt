== Description ==

Records visitor click positions and scroll depth on chosen pages and posts, and shows them as a device-split heatmap overlay to administrators on the live page.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate through the Plugins screen.

== Description ==

A Download CPT with a file-URL meta and a download-count meta (secure meta box) and a [downloads] shortcode listing published downloads as escaped links.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate through the Plugins screen.

== Description ==

A Wine CPT with a vintage meta (secure meta box), a hierarchical Region taxonomy and a Varietal taxonomy, and a [wines region="" varietal=""] shortcode filtering published wines, escaped. Escape all output, sanitize all input, and pair every state-changing action with a nonce AND a capability check. Remove posts and terms on uninstall.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate through the Plugins screen.
